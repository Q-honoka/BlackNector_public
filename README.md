# [Black Nector] 

<img width="80%" height="80%" alt="game" src="https://github.com/user-attachments/assets/b7fe8e26-c9a8-404d-be81-16d182624b66" />

鳥を操作して、少女をゴールまで導く横スクロールパズルアクションゲームです。
少女や敵は暗闇に入ると「ネスター」という存在に襲われるため、敵を暗闇に誘導しつつも少女は明るい場所を移動させるゲームです。
2年次のゲームゼミにて、暗闇にいるキャラクターを判別する暗闇判定を主に担当しました。
またチームメンバーが途中で減ったため、キャラクターとギミックは前任者から引き継いで制作を行いました。

## 🎮 ゲーム概要
- **ジャンル**: 横スクロールパズルアクション
- **プラットフォーム**: PC (Windows)
- **制作期間**: 約4ヶ月
- **言語**: C#
- **使用ツール**: Unity [バージョン： 6000.0.60f1], VisualStudio2022, Sourcetree, Git

## 🌟 実装のポイント
- **暗闇判定**: オブザーバーパターンを使用して、パフォーマンスを損なわないようにしました。
- **敵の視界の描画**: スクリプト内でメッシュを作成して、三角関数を用いて扇形の視界の頂点を算出するようにしました。

## 💡 こだわった点 
- **明るさ判定の自作**: Unityの既存の機能にはないため、三角関数を用いてスポットライトのなかにキャラクターがいるかを取得できるようにしました。
